**Embedded Systems** is a graduate-level course covering the design and programming of resource-constrained computing systems, from bare-metal microcontroller programming to real-time operating system fundamentals.

## Course map

| Week | Topic | Status |
|------|-------|--------|
| 01 | Introduction & microcontroller architecture | ✓ |
| 02 | GPIO, timers, and interrupts | ✓ |
| 03 | Serial communication — UART, SPI, I²C | ✓ |
| 04 | Memory-mapped I/O and DMA | ✓ |
| 05 | *(coming next week)* | — |

## Reference books

- *The Definitive Guide to ARM Cortex-M3 and Cortex-M4 Processors* — Joseph Yiu
- *Making Embedded Systems* — Elecia White
- *Real-Time Concepts for Embedded Systems* — Qing Li & Caroline Yao

## Tools used in this course

- **Toolchain**: GCC arm-none-eabi
- **IDE**: VS Code + Cortex-Debug extension
- **Hardware**: STM32F4 Discovery board
- **RTOS**: FreeRTOS (introduced in week 08)
